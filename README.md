# 求子三要

> 印光大师留给世间求子夫妇的“操作手册” —— 开源整理，免费流通，欢迎共创。

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)
[![PDF](https://img.shields.io/badge/%F0%9F%93%84-PDF%E4%B8%8B%E8%BD%BD-cb6f2a.svg)](#-pdf-下载)

印光大师应浙江永嘉张德田居士之请，作《礼念观音求子简疏》与《求子三要》。全书把求子拆成三件要事，再加一条求加持的路，条条都是可以照着做的方法，不是空泛的道理：

| | 三要 | 解决的 |
|---|---|---|
| 第一 | **保身节欲，以培先天** | 孩子有没有一个好身体、好脑力 |
| 第二 | **敦伦积德，以立福基** | 孩子有没有福报、能不能立得住 |
| 第三 | **胎幼善教，以免随流** | 孩子长大会不会走偏 |

三条之外，再以至诚心礼拜、称念观世音菩萨。**前三条是人要尽的本分，念菩萨是求加持**——大师说得极清楚：若三条不做，纵然菩萨满愿，人也是辜负了菩萨的深恩。

## 🤝 如何增砖添瓦

这是一册**越多人看，越应该越准**的书。欢迎以下任何一种参与：

1. **勘误校对** —— 发现错字、标点、引文出处问题，请 [开个勘误 Issue](../../issues/new?template=01-勘误.md)，一个字也好。
2. **补充事证** —— 你或你身边人依此法求子、育儿的真实经历，欢迎投稿（可匿名）。[投稿入口](../../issues/new?template=02-补充资料与事证.md)
3. **翻译** —— 译成任何语言，英/日/韩/越南语都欢迎。
4. **新版本排版** —— 注音版、大字版、口袋本、儿童读本、音频朗读……做好了开 Issue 登记链接，让更多人用得上。
5. **AI / Agent 共创** —— 本仓库预留了 [AGENTS.md](AGENTS.md)，里面有结构化的任务清单与协作规范。**如果你手头有 AI 编码助手（Claude Code / Cursor / WorkBuddy 等），把 AGENTS.md 喂给它，就可以直接开工。**

具体流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。全部贡献者会列入致谢名单。

## 🔁 重新生成 PDF

PDF 由 `text/` 下的 Markdown 编译而成，改动 Markdown 后可一键重新生成：

```bash
python tools/build_pdf.py            # 输出 pdf/求子三要.pdf（含页码）
python tools/build_pdf.py --no-pagenum
```

只依赖 Python 标准库 + 本机 Chrome / Edge（自动查找），Windows / macOS / Linux 均可运行。
