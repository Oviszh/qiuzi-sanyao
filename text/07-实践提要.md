# 实践提要

> 这一章是编者依前文整理出的**操作清单**，不是新增的开示。凡与大师原话有出入处，**一律以原文为准**。

---

## 一、求子三要速查

| 三要 | 具体做什么 | 关键节点 |
|---|---|---|
| **保身节欲，以培先天** | 夫妇分房/分床，断房事半年（至少百日，愈久愈好）；养足身体 | 受孕之前 |
| **敦伦积德，以立福基** | 孝亲敬长、夫妻和睦、善待眷属；心存慈善，存好心、说好话、行好事 | 始终 |
| **胎幼善教，以免随流** | 孕期端庄诚静、常念观音；产后教因果、八德，教念圣号 | 受孕之后，直至成年 |

贯穿始终：**早晚礼拜、持念“南无观世音菩萨”**，愈多愈好。

---

## 二、时间线（依《求子之道》《保身广嗣要义》整理）

### 阶段一：备孕（建议半年，愈久愈好）

- [ ] 夫妇**共同**约定，说明这是为祖宗继嗣的大事，不是谁为难谁。
- [ ] 另屋居住；无多余房间则**另床**；再不然各盖一被。
- [ ] 平时不以妻作妻想，当作姊妹想（大师语），不起邪念。
- [ ] 身体有病先治病，不勉强。
- [ ] 调经期：月经以三十天一来为正常；不调者先看中医调理。
- [ ] 心存慈善，随分随力利人利物；可印施、流通善书（《感应篇》《阴骘文》等）。
- [ ] 早晚礼拜称念观世音菩萨；读诵《礼念观世音菩萨求子疏》。

### 阶段二：受孕时机

- [ ] 待**月经干净三日之后**，择天气清明、日期吉祥之夜。
- [ ] 月经未净，切不可同房。
- [ ] 避开：大风大雨、雷电震闪、大冷大热、日蚀月蚀。
- [ ] 避开：朔望日（初一、十五）前一夜、庚申日、甲子日、本人生日、每月二十八日。
- [ ] 避开：神像前、棺材旁、持斋祭祀日、日月灯光之前。
- [ ] 避开：醉酒饱饭后、远行乘车船后二三天内、身体有小病时。
- [ ] 五更半夜阳气初生之时，行一次当百次，切不可。

### 阶段三：怀孕之后

- [ ] **断房事**——这是保胎第一义。三月前犯之易漏下胎动；三月后犯之则胞衣厚而难产。
- [ ] 形容端庄诚静，语言忠厚平和，行事孝友恭顺。
- [ ] 行住坐卧常念观音圣号；不洁处、睡时默念。
- [ ] **不可生气**。生大气则堕胎，且乖戾之气过之于子。
- [ ] 可多发善愿、多行善事，回向胎儿。

### 阶段四：临产

- [ ] **此时不可默念，要出声念。**
- [ ] 产妇自念，家属在旁大声助念。
- [ ] 以此因缘，决定不遭难产及产后诸险。

### 阶段五：哺乳与幼教

- [ ] 餧奶时必须心气和平。生大气则奶成毒——须先放下，心平气和过半天再餧；餧前先挤掉半茶碗，奶头揩过再餧。
- [ ] 幼儿初开知识，即讲因果报应：利人利物者必昌，害人害物者必亡。
- [ ] 教八德：**孝、悌、忠、信、礼、义、廉、耻**。
- [ ] 立规矩：不说谎、不撒娇疯颠、不拿人东西、不打人骂人、不糟践虫蚁字纸五谷。
- [ ] 教他常念观音圣号，消除宿世恶业，增长善根。

## 三、每日功课（可自行增减）

| 时段 | 功课 |
|---|---|
| 早 | 礼拜观世音菩萨；念圣号若干（或读诵《礼念观世音菩萨求子疏》） |
| 日间 | 行住坐卧随缘默念；以善心待人处事，随缘劝化 |
| 晚 | 礼拜；念圣号若干；反省今日身口意，不善者明日改之 |
| 睡时 | 宜着衫裤，心存恭敬，默念 |

> 睡时宜默念，不宜出声；若六字难念，可去“南无”二字，但念“观世音菩萨”五字。白衣咒念也好，不念也无碍。

---

## 四、最容易出问题的三件事

1. **等不及。** “断欲愈久愈好”，才过一两个月就同房，大师说这仍属先天不足，其子决不能有成就。
2. **以为天天同房才容易怀。** 恰恰相反——精薄如秕种，难生，生亦难成。
3. **只求菩萨，不改自己。** 三要是人该尽的本分。菩萨满愿而人不奉行，是为辜负圣恩。

---

## 五、一句总持

> 保身节欲以培先天，敦伦积德以立福基，胎幼善教以免随流；
> 再以至诚，礼念观世音菩萨。

南无大慈大悲救苦救难广大灵感观世音菩萨。
